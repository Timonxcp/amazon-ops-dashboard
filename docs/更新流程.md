# 周更业绩 · 流程说明

## 每周一次：导入 3 份 Excel

从领星导出（下载中心）后，在大盘顶部点 **「导入业绩」**，一次选择 3 个文件：

| 槽位 | 文件 | 领星路径 |
|------|------|----------|
| 1 | **产品表现** | 产品表现 / 导出 · 时间范围选本周或全量 · 原币种 · 统计维度 ASIN · 不汇总 · 按天 |
| 2 | **广告活动报告** | 广告 / 下载中心 / 广告类型全选 · 报告类型「广告活动」 |
| 3 | **SP 广告位** | 广告 / 下载中心 / 类型 SP · 报告类型「广告位」 |

### 处理流程（自动）

1. 识别三表表头并解析  
2. 按日 / MSKU / 活动 / 广告位 **合并**（同 key 覆盖，增量追加）  
3. 重建 KPI、趋势、产品榜、广告结构  
4. **本地立即生效**（当前浏览器）  
5. 自动下载新的 `js/data.enc.js`  

### 发布到线上

把下载的 `data.enc.js` 替换仓库内同名文件并 push：

```bash
git add js/data.enc.js
git commit -m "data: weekly performance import"
git push
```

GitHub Pages 会在约 1 分钟内更新；同事的邀请链接不变。

## 每日自动：西柚 ASIN / 关键词流量

无需打开电脑或网站，由 GitHub Actions 定时执行（`.github/workflows/xydc-daily.yml`）。

### 一次性配置 Secrets

仓库 → Settings → Secrets and variables → Actions：

| Secret | 含义 |
|--------|------|
| `XYDC_API_KEY` | 西柚洞察 OpenAPI Key |
| `DASHBOARD_ACCESS_CODE` | 与邀请链接一致的访问码（当前 `RB5t5CIsfYn9`） |

### 产品清单

维护 `config/products.json`（msku / asin）。增删 SKU 后改此文件即可。

### 本地手动跑一次

```bash
$env:XYDC_API_KEY="..."
$env:DASHBOARD_ACCESS_CODE="RB5t5CIsfYn9"
node scripts/xydc-daily.mjs
```

产出：`js/keywords.enc.js`（仅关键词包，不影响周更业绩包）。

## 密钥轮换

重跑 `node scripts/build-data.mjs` 会生成新访问码；同步更新：

1. 本地 `ACCESS-SECRETS.local.md`  
2. GitHub Secret `DASHBOARD_ACCESS_CODE`  
3. 重新分发邀请链接
